How It Works
Four phases from raw data to trust report.
Phase 01
Data Ingestion & Claim Extraction
PDF text extraction, unicode normalization, entity classification into Certification / Project / Internship / Education.
Phase 02
Multi-Tiered Verification
Three layers of scrutiny: local PDF proof (strongest), certificate link scraping, GitHub API, DuckDuckGo plausibility.
Phase 03
Decision Engine
Evidence is weighed per claim type. Each claim is categorized as Verified, Unknown, or Suspicious with a reason attached.
Phase 04
Scoring & PDF Report
Trust Score calculated from verified ratio. A multi-page PDF report is generated with full claim breakdown and evidence trail.
